# task_code — 正式题目：检测球 + 串口发坐标

电赛题目的正式实现（从 `v1.0.py` 起编号）。在去畸变画面上跑 YOLO11n NCNN 球检测，
每帧选主目标球心，把 X/Y 经 USB 串口发给下位机（单片机）。摄像头、串口两条链路都支持热插拔。

## 运行

```bash
# 主程序：实时检测 + 发坐标（需显示器/桌面会话）
/home/hao/vision_env/bin/python3 code/task_code/v1.0.py
#   --size 320|416|640   初始模型规格（默认 320；运行时 1/2/3 可切）
#   --conf 0.25          置信度阈值
#   --no-serial          只看检测、不发串口
#   --any                串口找不到固定口时放宽到任意 CH340/ttyUSB

# 串口收包监视（调试用，可纯 SSH 跑）
/home/hao/vision_env/bin/python3 code/task_code/serial_test.py
#   --hex / --raw / --port / --baud / --any
```

`v1.0.py` 按键：`1/2/3` 切规格、`u` 切去畸变、`q` 退出。画面标出主目标球心与坐标，
HUD 显示 `serial:TX#计数`，底部显示最近发出的一帧原文。

## 配置持久化（自动保存，下次沿用）

`v1.0.py` 的 **模型规格 / 是否去畸变 / 置信度** 会存到 `task_config.json`（本机状态，已 gitignore）：

- 运行时用 `1/2/3` 切规格、`u` 切去畸变都会**自动写回**，退出时也保存一次；
- **下次启动自动读上次的值**，无需再带参数；首次运行按默认 `size=320 / 去畸变开 / conf=0.25`；
- 命令行 `--size / --conf` 会**覆盖**配置并保存为新默认（`--size 416` 跑一次，以后就默认 416）；
- 配置项定义在 `config.py`（`DEFAULTS`）。文件损坏/被手改坏了会安全退回默认，不会崩。

## 通信格式（上位机→下位机）

NMEA 风格的带校验 ASCII 帧，可读、自同步、带 XOR 校验：

```
$BALL,<found>,<x>,<y>,<n>*<CHK>\r\n
```

| 字段 | 含义 |
|---|---|
| `$` | 帧起始 |
| `BALL` | 报文类型（固定） |
| `<found>` | 1=检测到球，0=没检测到 |
| `<x> <y>` | **主目标**球心像素坐标（整数）；`found=0` 时为 `0,0` |
| `<n>` | 本帧检测到的球总数 |
| `*` | 校验分隔符 |
| `<CHK>` | `$` 与 `*` 之间所有字符逐字节 XOR，两位大写十六进制 |
| `\r\n` | 帧结束 |

- 坐标系：去畸变后 **640×480** 画面，原点左上角，x 向右∈[0,639]、y 向下∈[0,479]。
- 主目标 = 面积最大的那个球。发送频率 = 处理帧率（320 规格约 17 帧/秒），每帧一条。

样例（校验值已实测）：
```
$BALL,1,321,240,3*07      检测到，主目标(321,240)，共3球
$BALL,1,314,336,10*33     主目标(314,336)，共10球
$BALL,0,0,0,0*03          没检测到球
```

下位机（STM32）建议用状态机按 `$`…`\n` 收整行，先校验 XOR、不过就整帧丢弃，
过了再 `sscanf(line, "$BALL,%d,%d,%d,%d", &found,&x,&y,&n)`。改字段/坐标系只改
`protocol.py` 一处，下位机同步。

## 热插拔说明

- **串口**：默认只认固定物理 USB 口（`serial_link.PREFERRED_BYPATH`，绑定 by-path，不受
  ttyUSB 编号变化影响）。换插别的口就改那个常量或用 `--port`。启动没插会循环等，
  运行中拔掉/插回自动重连，画面不受影响。
- **摄像头**：启动没插循环等待；运行中掉线显示 `waiting for camera...` 占位、插回自动续；
  期间仍可按 `q` 退出。
